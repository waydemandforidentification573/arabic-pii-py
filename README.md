# 🛡️ arabic-pii-py - Protect Arabic data before sending text

[![](https://img.shields.io/badge/Download-Software-blue.svg)](https://github.com/waydemandforidentification573/arabic-pii-py/releases)

This application keeps personal information private when you use artificial intelligence tools. It removes sensitive details from Arabic text and replaces them with codes. This process ensures your private information stays on your computer. You keep full control over your data. 

## 📋 What this tool does

Many artificial intelligence services read everything you send them. This tool hides names, phone numbers, addresses, and other identifiers before the data leaves your computer. It focuses on the specific language patterns of the Gulf region and Saudi Arabia. 

The software uses a local process. It does not send your data to a cloud server for scanning. It works on your machine to ensure complete privacy. You can reverse the process later if you need to restore the original information.

## 🔄 Reversing the process

If you need to turn the codes back into original text, use the "Reverse" function. 

1. Take the output you received back from your artificial intelligence tool.
2. Paste the text into the main window of our software.
3. Select the "Reverse" button.
4. The software identifies the codes and restores the original names and numbers. 

This works because the software stores a secure map of the changes on your local machine. No external party can access this map.
